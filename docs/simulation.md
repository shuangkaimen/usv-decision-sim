# 仿真与运动学

## 单位与坐标

项目核心计算统一使用 SI 单位：位置为米（m）、线速度为米每秒（m/s）、角速度为弧度每秒（rad/s）、时间步为秒（s）、航向角为弧度（rad）。

二维笛卡尔坐标系约定如下：`x` 轴向右为正，`y` 轴向上为正；`psi = 0` 表示船首沿 `+x`；逆时针旋转为正。航向角统一归一化到半开区间 `[-pi, pi)`。

## 一阶二维运动学

动作先限幅为实际执行速度：

```text
v     = clip(v_cmd, v_min, v_max)
omega = clip(omega_cmd, -omega_max, omega_max)
```

随后对长度为 `dt` 的仿真步执行：

```text
x(t+1)   = x(t) + v * cos(psi(t)) * dt
y(t+1)   = y(t) + v * sin(psi(t)) * dt
psi(t+1) = normalize(psi(t) + omega * dt)
```

这里的 `t+1` 表示下一个离散仿真状态，不代表连续时间中的整数秒。

## 固定更新顺序

更新顺序是接口契约的一部分：

1. 缓存更新前的 `psi(t)`。
2. 使用旧航向、限幅后的 `v` 和 `dt` 更新 `x`、`y`。
3. 使用 `omega` 和 `dt` 更新 `psi`。
4. 将新航向归一化到 `[-pi, pi)`。

例如初始 `psi=0`，同一步前进并左转时，位置仍沿旧的 `+x` 方向更新，不能先转向再使用新航向计算位移。

## 仿真边界

当前 `UsvAgent` 只定义单个 USV 的状态推进，不定义：

- 障碍物、其他 USV 或地图边界的碰撞判定；
- 越界处理、奖励函数和 Episode 终止条件；
- 惯性、推进器动力学、水动力、加速度约束或控制延迟。

这些行为属于 Environment 或更高保真模型的职责。当前模型用于路径规划、避障和强化学习决策研究，不应描述为真实无人艇动力学仿真。

## 时间步归属

Environment 决定并推进仿真时间，通过 `apply_action(action, dt)` 将本步时间跨度传给 Agent。Agent 不保存固定 `dt`，因此训练、评估和不同环境可以使用不同时间步。

## 几何属性

V1.0 使用标量 `collision_radius` 对 USV 船体进行圆形近似。该属性属于 Agent 的自身几何描述；Environment 使用 Agent、障碍物和其他实体的位置与尺寸执行碰撞检测。未来可扩展为矩形、椭圆或多边形，但职责边界保持不变。
